If you're writing a Deskflow-compatible app then you'll need to use the Deskflow protocol.

These files describe the protocol:

- [`ProtocolTypes.h`](https://github.com/deskflow/deskflow/blob/master/src/lib/deskflow/ProtocolTypes.h)
- [`ProtocolTypes.cpp`](https://github.com/deskflow/deskflow/blob/master/src/lib/deskflow/ProtocolTypes.cpp)

The [μSynergy ](https://github.com/symless/synergy-micro-client) (μ as in _micro_) code is a good example of how to use this protocol:
- [`uSynergy.h`](https://github.com/symless/synergy-micro-client/blob/master/uSynergy.h)
- [`uSynergy.c`](https://github.com/symless/synergy-micro-client/blob/master/uSynergy.c)
