[Synergy](https://symless.com/synergy) sponsors the Deskflow project by contributing code and providing financial support.

The Deskflow project was established to cultivate community-driven development where everyone can collaborate. Deskflow is the official upstream project for [Synergy](https://symless.com/synergy).

![Sponsored by: Synergy](https://raw.githubusercontent.com/deskflow/deskflow-artwork/b2c72a3e60a42dee793bd47efc275b5ee0bdaa5f/misc/synergy-sponsor.svg)

# Comparison

| | **Deskflow** | **Synergy** |
| --- | --- | --- |
| **Licensing** | Completely open source (GPLv2) | Mostly open source (GPLv2 and proprietary) |
| **Goals** | Community-driven project focused entirely on goals decided on by the developer community. | Driven by customer needs, for-profit, adapted to fit consumer, business, and enterprise requirements. |
| **Benefits** |  Faster release schedule and focuses on bleeding edge changes. | Quality assurance, warranty, insurance, standards certifications, technical support, legacy OS support. |
