[Synergy](https://symless.com/synergy) sponsors the Deskflow project by contributing code and providing financial support, ensuring the project's sustainability. Deskflow is the official upstream project for Synergy, focusing on community-driven development. Synergy builds upon Deskflow, adding proprietary features tailored for enterprise and commercial use.

![Sponsored by: Synergy](https://raw.githubusercontent.com/deskflow/deskflow-artwork/b2c72a3e60a42dee793bd47efc275b5ee0bdaa5f/misc/synergy-sponsor.svg)

# Comparison

| | **Deskflow** | **Synergy** |
| --- | --- | --- |
| **Licensing** | Completely open source (GPLv2). | Mostly open source (GPLv2 and proprietary). |
| **Development Focus** | Community-driven, rapid iteration. | Customer-focused, emphasizing stability and support. |
| **Release Cycle** | Frequent updates with cutting-edge features. | Scheduled releases with thorough QA processes. |
| **Support** | Community forums and contributions. | Professional support, warranties, and certifications. |
| **Compatibility** | Latest Windows, macOS, Linux, BSD | Broad OS support, including legacy systems. |
