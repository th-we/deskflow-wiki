There are several forks, derivatives, and downstream projects based on the original Synergy project.

# Fork History

- 2001: Synergy
- 2018: Synergy forked to Barrier
- 2021: Barrier forked to Input Leap
- 2024: Synergy renamed Deskflow

# Comparison

Accurate as of Oct 2024.

| Project | Base | Started | Type | Status | Philosophy |
| --- | --- | --- | --- | --- | --- |
| Synergy (<=v1.15) | - | 2001 | Original | Active | Mostly open source (GPLv2), stability, customer-focused, for-profit |
| Barrier | Synergy v1.9 | 2018 | Fork | Dead* | GPLv2, removal of customer-related code |
| Input Leap | Barrier v2.x | 2021 | Fork | Active | GPLv2, stability, legacy support, optional code reviews |
| Deskflow | Synergy v1.15 | 2024 | Upstream | Active | GPLv2, leading edge, community-driven, no customer code |
| Synergy (>v1.15) | Deskflow | 2024 | Downstream | Active | GPLv2, stability, legacy support, customer-focused, for-profit |
| Synergy (v3.x) | Synergy v1.x | 2023 | Downstream | Active | Proprietary, Electron, easy config, customer-focused, for-profit |

\* As of Oct 2024, the last commit on Barrier was `653e4ba` (2 years ago). The general view is that it is a dead project.
