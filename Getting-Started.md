# Get the Code

First, you'll need to get the code via git.

1.
    1. `$ git clone git@github.com:symless/synergy-core.git`
    1. `$ cd synergy-core`
1. Switch to the right branch
    * Stable v1.x: `$ git checkout v1.x` (replace `x` with the version you need - type `git tag` and space through for a list)
    * Beta v2.x: `$ git checkout master` (this is where you are by default)
