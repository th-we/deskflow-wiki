# Get the Code

First, you'll need to get the code via git.

1. `$ git clone git@github.com:symless/synergy-core.git`
1. Switch to the right branch
    1. Stable v1.x: `$ git checkout v1.x` (replace `x` with the version you need)
    1. Beta v2.x: `$ git checkout master` (this is where you are by default)
