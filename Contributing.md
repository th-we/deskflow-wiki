There are many ways to contribute to the Deskflow project.

# Getting started

Deskflow is an open source project, so we welcome contributions.
- A great place to start is by solving issues labelled:  
  [![Good first issues](https://img.shields.io/github/issues/deskflow/deskflow/good%20first%20issue)](https://github.com/deskflow/deskflow/labels/good%20first%20issue)
- Earn money by solving issues with bounties:  
  [![Open bounty issues](https://img.shields.io/github/issues/deskflow/deskflow/%F0%9F%92%8E%20bounty)](https://github.com/deskflow/deskflow/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22%F0%9F%92%8E%20bounty%22)
- Read the [[Hacking Guide]] to ensure your PR gets landed.
- Get started by [[Building]] the project from source.

# Join our community

- Main discussion on Matrix: [`#deskflow:matrix.org`](https://matrix.to/#/#deskflow:matrix.org)
- Discussion also happens on IRC: `#deskflow` or `#deskflow-dev` on [Libera Chat](https://libera.chat/)
- Start a [new discussion](https://github.com/deskflow/deskflow/discussions) on our GitHub project
