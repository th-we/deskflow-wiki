# Getting started

Deskflow is an open source project, so we welcome contributions. You may work any an Issues you want to. We do not assign issues to non members so please do not ask to be assigned an issue before working on it. If an issue you want to work on is assigned to someone you should ask them if they are still working on it before working on your own fix.

- A great place to start is by solving issues labelled:

)](https://github.com/deskflow/deskflow/labels/good%20first%20issue)
- Read the [[Hacking Guide]] to ensure your PR gets landed.
- Get started by [[Building]] the project from source.
- Help us with [[triaging issues|Triaging issues]].

# Join our community

- Main discussion on Matrix: [`#deskflow:matrix.org`](https://matrix.to/#/#deskflow:matrix.org) ([Matrix clients](https://matrix.org/ecosystem/clients/))
- Discussion also happens on IRC: `#deskflow` or `#deskflow-dev` on [Libera Chat](https://libera.chat/)
- Start a [new discussion](https://github.com/deskflow/deskflow/discussions) on our GitHub project.

# Our values

- Motivated by the community interests (not business-driven)
- Privacy by default (e.g. update check is off by default)
- Leading edge releases (we don't focus on supporting older systems)
- Decisions are discussed and documented publicly with majority rule
- AI is a tool, use it but don't paste walls of AI text to each other
- Have fun; we don't need to worry about impressing anyone

# More ways to contribute

- Improve or write documentation
- Translate the GUI into other languages
- Report bugs or suggest features
- Test software and provide feedback
- Design UI/UX or improve graphics
- Moderate forums or community chats
- Write blog posts or tutorials
- Curate or organize issues (triage)
- Help with project management or planning
- Promote the project on social media or in talks
